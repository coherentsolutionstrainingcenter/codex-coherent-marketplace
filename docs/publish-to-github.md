# Publish The Coherent Marketplace To GitHub

This guide is for the owner of this repository. It explains how to verify the marketplace, create a GitHub repository, and push the plugin marketplace so other people can attach it to their local Codex app.

## 1. Confirm The Repository Structure

From the repository root, you should have:

```text
.agents/plugins/marketplace.json
plugins/coherent-recruiter/.codex-plugin/plugin.json
plugins/coherent-recruiter/skills/
plugins/coherent-recruiter/docs/
plugins/coherent-recruiter/assets/icon.png
plugins/coherent-hr/README.md
plugins/coherent-sales/README.md
plugins/coherent-marketing/README.md
plugins/coherent-delivery/README.md
plugins/coherent-project-management/README.md
plugins/coherent-business-analytics/README.md
README.md
docs/
```

Do not publish `plugins/cache/`. That folder is generated by local Codex installs and is ignored by `.gitignore`.

## 2. Understand The Naming

Use these names unless you intentionally decide to rename the marketplace:

```text
Marketplace ID: coherent
Marketplace display name: Coherent Marketplace
Recruiter plugin ID: coherent-recruiter
Recruiter plugin display name: Coherent Recruiter
```

The ID values are used in config files, so keep them lower-case and hyphenated. The display names are what people see inside Codex.

## 3. Update Public Metadata

Before publishing, open `plugins/coherent-recruiter/.codex-plugin/plugin.json` and update public metadata if needed:

```json
{
  "author": {
    "name": "Coherent Solutions",
    "email": "<public support email>",
    "url": "https://www.coherentsolutions.com/"
  },
  "homepage": "https://github.com/coherentsolutionstrainingcenter/codex-coherent-marketplace",
  "repository": "https://github.com/coherentsolutionstrainingcenter/codex-coherent-marketplace"
}
```

Keep `"name": "coherent-recruiter"` unchanged unless you also rename the folder and marketplace entry.

## 4. Verify The Marketplace File

The marketplace lives at `.agents/plugins/marketplace.json`.

It should contain:

```json
{
  "name": "coherent",
  "interface": {
    "displayName": "Coherent Marketplace"
  },
  "plugins": [
    {
      "name": "coherent-recruiter",
      "source": {
        "source": "local",
        "path": "./plugins/coherent-recruiter"
      },
      "policy": {
        "installation": "AVAILABLE",
        "authentication": "ON_INSTALL"
      },
      "category": "Productivity"
    }
  ]
}
```

Validate the JSON:

```bash
jq . .agents/plugins/marketplace.json
jq . plugins/coherent-recruiter/.codex-plugin/plugin.json
```

If `jq` is not installed, use:

```bash
python3 -m json.tool .agents/plugins/marketplace.json
python3 -m json.tool plugins/coherent-recruiter/.codex-plugin/plugin.json
```

## 5. Initialize Git

Run this from the repository root:

```bash
git init
git add .gitignore README.md docs .agents/plugins/marketplace.json plugins/coherent-*
git status
git commit -m "Publish Coherent Codex plugin marketplace"
```

The `git status` output should not include `plugins/cache/` or `.DS_Store`.

## 6. Create The GitHub Repository

Option A: GitHub CLI.

```bash
gh repo create coherentsolutionstrainingcenter/codex-coherent-marketplace --public --source=. --remote=origin --push
```

For a private marketplace, use `--private` instead of `--public`.

Option B: GitHub website.

1. Open GitHub and create a new empty repository named `codex-coherent-marketplace`.
2. Do not initialize it with a README, license, or `.gitignore`, because this folder already has those docs.
3. Copy the repository URL.
4. Run:

```bash
git remote add origin https://github.com/coherentsolutionstrainingcenter/codex-coherent-marketplace.git
git branch -M main
git push -u origin main
```

## 7. Test A Fresh Clone

After pushing, test the repository the same way another user would:

```bash
mkdir -p ~/codex-marketplaces
git clone https://github.com/coherentsolutionstrainingcenter/codex-coherent-marketplace.git ~/codex-marketplaces/coherent-marketplace-test
python3 -m json.tool ~/codex-marketplaces/coherent-marketplace-test/.agents/plugins/marketplace.json
python3 -m json.tool ~/codex-marketplaces/coherent-marketplace-test/plugins/coherent-recruiter/.codex-plugin/plugin.json
```

If both JSON files validate, the marketplace is ready to share.

## 8. Share The User Instructions

Send users the repository URL and this guide:

```text
https://github.com/coherentsolutionstrainingcenter/codex-coherent-marketplace/blob/main/docs/use-this-marketplace.md
```

When you add more plugins later, place them under `plugins/<plugin-name>/` and append an entry to `.agents/plugins/marketplace.json` with a relative `source.path`.
