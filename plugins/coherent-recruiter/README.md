# Coherent Recruiter Plugin

This local Codex plugin bundles recruiter-focused skills for Coherent recruiting workflows and adds an orchestration skill for broader recruiter tasks. It is intended for local installation through the Coherent Marketplace so the Coherent Recruiter persona and its specialist skills can travel together.

## Included Skills

- `coherent-recruiter-orchestrator`
- `candidate-faq-responder`
- `candidate-relevance-ranker`
- `cv-format-converter`
- `follow-up-finder`
- `jd-drafter`
- `job-request-gap-analyzer`
- `outreach-library`
- `pipeline-report-generator`
- `prescreen-call-transcriber`
- `recruiter-boolean-builder`
- `recruiter-skill-creator`
- `rejection-letter-drafter`
- `scorecard-writer`

## Human Guides

Human-facing usage guides are packaged in:

- `docs/human-guides/`

Each guide gives recruiters examples, workflow ideas, and operating notes for the matching skill.

## Typical Prompts

- Turn this hiring intake into JD gaps, sourcing strings, and outreach drafts.
- Compare these candidate profiles to the role and prepare recruiter review notes.
- Convert this CV and interview notes into a client-ready profile and scorecard.
- Draft a candidate follow-up sequence from this outreach history.
- Create a pipeline report from this ATS export.
- Turn this Custom GPT recruiter workflow into a Codex skill package.

All outputs are drafts or triage aids for recruiter validation.
