# Coherent Recruiter Plugin Docs

This folder contains human-facing usage guides packaged with the local `coherent-recruiter` plugin.

## Human Guides

The `human-guides/` folder contains one guide per standalone recruiter skill:

- `candidate-faq-responder-skill.md`
- `candidate-relevance-ranker-skill.md`
- `cv-format-converter-skill.md`
- `follow-up-finder-skill.md`
- `jd-drafter-skill.md`
- `job-request-gap-analyzer-skill.md`
- `outreach-library-skill.md`
- `pipeline-report-generator-skill.md`
- `prescreen-call-transcriber-skill.md`
- `recruiter-boolean-builder-skill.md`
- `recruiter-skill-creator-skill.md`
- `rejection-letter-drafter-skill.md`
- `scorecard-writer-skill.md`

These guides are for recruiters and workflow owners. The executable Codex skill instructions live in `../skills/<skill-name>/SKILL.md`.
